Tetoronom Analysis Pipeline

상세 데이터 전처리 및 분석 방법론

⛰️ 1. 핵심 피크 검출 로직

착지 충격을 식별하는 기반 알고리즘. 다른 파생 지표들의 계산 기준점이 됩니다.

피크 탐지

입력 신호 Shank의 합성가속도(Resultant Acceleration)를 사용합니다.
스무딩 (Smoothing) 데이터에 4차 Butterworth Low-pass Filter (Cutoff: 15Hz)를 적용합니다. 보행 중 인체 가속도 신호의 주요 에너지는 대체로 15Hz 이하에 분포하며, 그보다 높은 성분에는 착지 충격의 순간 성분, 센서 고정 상태, 피부/연부조직 움직임에서 유래한 고주파 성분이 섞일 수 있습니다. 따라서 15Hz cutoff는 보행 신호의 주 성분을 보존하면서 고주파 노이즈를 줄이기 위한 보수적 전처리 선택입니다.[1][2]
피크 임계값 설정 • Height (절대 높이): 사람마다 체중이나 충격량 범위가 다르므로 동적 임계값을 제거했습니다.
• Prominence (돌출도): 0.2 * g (약 1.96m/s²). 최소한 주변 노이즈보다는 0.2g 이상 확연하게 솟아오른 뚜렷한 피크만을 1차 후보로 인정합니다.
• 최소 간격 (Distance): 280ms (FS 기준 16샘플)를 주어 이중 피크(Double peak) 검출을 방지합니다. 280ms는 약 214 steps/min까지의 매우 빠른 step frequency를 허용하는 값이며, 야외 달리기 연구에서 imposed step frequency가 140~200 steps/min 범위로 설정된 점을 고려하면 본 데이터의 중복 피크 억제 기준으로 보수적입니다.[3]
IQR 이상치 필터 충격량 분석 시 외란성 피크를 제거하기 위해 검출된 피크 높이들을 대상으로 1.5 * IQR (Q1-1.5*IQR ~ Q3+1.5*IQR) 범위를 벗어나는 피크는 배제합니다.

📊 2. 산출 지표별 상세 처리 방법

A. 케이던스 (Cadence)

사용 데이터 Foot row 기준의 shank_free_acceleration_resultant_m_s2 (착지 시점과 가장 인접하게 기록됨)
적용 처리 Smoothing 적용 IQR 필터 적용
버터워스 필터(15Hz)를 적용하여 잔떨림을 제거하고 IQR 필터를 통해 외란성 피크를 배제한 후, 총 정상 피크 개수를 구합니다. 편측(Unilateral) 센서이므로 도출된 케이던스에 x 2.0 (Bilateral 추정)을 수행하여 분당 걸음 수(steps/min)로 환산합니다.

B. 정강이 IMU Shock/Load Proxy (Shank Impact Peak Analysis)

사용 데이터 Shank row의 shank_free_acceleration_resultant_m_s2 (합성가속도)만을 사용하여 IMU 기반 shock/load proxy를 구합니다. 센서 부착 각도에 상관없이 3차원으로 발생하는 가속도 응답을 파악하기 위해 Z축이 아닌 합성가속도를 사용합니다.
적용 처리 (Peak g) Smoothing 적용 IQR 필터 적용
검출된 합성가속도 피크 값을 중력가속도(9.81)로 나누어 평균 Peak g를 산출합니다.
적용 처리 (Resultant RMS) 합성가속도의 제곱평균제곱근(RMS)을 구하여 걷는 동안 발생하는 전반적인 부하(Loading Index)를 정량화합니다: sqrt(mean(resultant^2))
적용 처리 (Acceleration-time load proxy) 합성가속도(Resultant)는 세 축의 제곱의 합의 제곱근(sqrt(X² + Y² + Z²))으로 계산되므로 수학적으로 항상 0 이상(양수)입니다. 따라서 특정 착지 구간(Stance phase)만 어렵게 잘라내지 않고, 전체 측정 구간의 연속된 값을 그대로 시간 간격(dt)에 대해 적분(np.trapz)합니다.
* 이유와 근거 (PlayerLoad™의 한계와 가속도 기반 부하 지표의 명확화): 스포츠 현장에서는 PlayerLoad™처럼 가속도 기반 누적 부하 지표가 널리 사용되지만, PlayerLoad는 장치 간 차이, 임의 단위(AU), 알고리즘 정의의 불투명성 때문에 해석에 주의가 필요합니다.[4][5]
따라서 본 파이프라인의 Impulse 항목은 지면반력에 질량을 곱해 계산한 GRF impulse 또는 biomechanical impulse가 아니라, 합성가속도 크기를 시간에 대해 적분한 acceleration-time integral proxy입니다. 이 지표는 조건 간 누적 가속도 노출을 비교하기 위한 탐색적 외부 부하 지표이며, 가속도 기반 metric은 수식과 단위를 명확히 보고해야 한다는 최근 검토 문헌의 권고와 맞추어 해석합니다.[6]
마지막으로 이렇게 구한 총 면적을 총 측정 시간으로 나누어 초당 누적 가속도 노출량(Total acceleration-time load over time)를 구합니다.

C. Step Interval Variability (Step Interval CV)

사용 데이터 Foot row 기준의 합성가속도 피크 발생 시간
적용 처리 Smoothing 적용 IQR 필터 적용
케이던스와 동일하게 15Hz 버터워스 필터 및 IQR 이상치 제거를 거쳐 얻어진 정상 피크들 간의 시간 간격(Interval, sec) 배열을 도출합니다. 이 간격들의 표준편차(SD)를 평균으로 나누어 CV% (Coefficient of Variation)를 산출합니다.
* 이유와 근거 (왜 SD가 아닌 CV인가?): 보폭 시간(Interval)은 달리는 속도에 따라 평균값이 크게 달라집니다. 느리게 뛰는 사람은 원래 평균 시간 자체가 길기 때문에 단순 표준편차(SD)도 자연스럽게 크게 나옵니다. 따라서 평균의 크기와 무관하게 '상대적인 변동성'을 공정하게 비교하기 위해 평균으로 나누어주는 CV%를 사용하는 것이 보행 변동성 분석에서 널리 쓰이는 방식입니다.[7][8]
* 이 지표를 보는 이유: 걸음걸이가 규칙적일수록 발을 내딛는 시간 간격(평균) 대비 변동(표준편차)이 적어 CV%가 낮게 나옵니다. 즉, 값이 낮을수록 step timing variability가 낮다는 의미이며, 임상적 안정성과 직접 등치하지 않습니다.

D. 골반 각도 변동성 (Pelvis Pitch/Roll Angular Variability)

분석 목적 골반의 가동 범위(ROM) 자체가 중요한 것이 아니라, 걷거나 뛸 때 골반 Pitch/Roll 각도가 얼마나 크게 변동하는지를 평가합니다. 이 값은 angular variability 지표이며, 임상적 안정성으로 직접 등치하지 않습니다.
사용 데이터 Hip 센서의 hip_quaternion_pitch_deg (수직 상하 틸트) 및 _roll_deg (좌우 회전/기울기)
적용 처리 (안정성) Smoothing 적용
센서 자체의 잔떨림이 골반 각도에 영향을 미치는 것을 막기 위해 골반 각도 데이터에도 15Hz 버터워스 필터를 선행 적용합니다.
이후 골반의 수직/좌우 각도 변동성을 파악하기 위해 Pitch와 Roll의 표준편차(SD)를 측정합니다. 값이 낮을수록 angular variability가 낮다는 의미입니다.
* 이유와 근거 (왜 CV가 아닌 SD인가?): 골반 각도(Roll, Pitch)는 0도(중립 자세)를 기준으로 앞뒤/좌우로 진동하는 데이터입니다. 만약 평균 자세가 0도에 가깝다면, 이를 평균으로 나누는 CV 공식(SD / 평균)에서 분모가 0에 수렴해 값이 무한대로 폭발하는 수학적 오류가 발생합니다. 따라서 영점(Zero-point)을 교차하는 각도(Kinematics) 데이터의 흔들림을 평가할 때는 비율(CV)이 아닌 절대적인 각도 진폭인 표준편차(SD)나 RMS를 사용하는 것이 타당합니다.[8][9]
추가로 각도의 미분값에 FS를 곱해 각속도의 제곱평균제곱근(Vel RMS)을 산출하여 얼마나 빠르고 거칠게 요동치는지도 측정합니다.

E. 발목 거동 (Ankle Kinematics)

사용 데이터 Foot 센서의 ankle_dorsiflexion_plantarflexion_deg 및 _inversion_eversion_deg
적용 처리 Smoothing 적용
발목 각도 신호 역시 고주파 노이즈 제거를 위해 15Hz 버터워스 필터를 먼저 적용합니다.
보폭(Stride)별로 분할하여 전체 가동 범위(ROM)의 평균을 산출합니다.
추가로 각 보폭 구간 내에서 발생하는 최대 양수 피크(Dorsiflexion)들의 평균과, 최대 음수 피크(Plantarflexion)들의 평균을 계산합니다. (Plantarflexion 평균은 해석의 편의를 위해 abs()를 적용해 절대값(양수)으로 변환하여 보고합니다.)

📈 3. 통계 검정 (Statistical Tests) 처리 로직

조건 간 차이의 유의성을 분석하기 위한 검정 방법론입니다. (비교 대상: Control → Metro, Control → Tape, Control → Tape+Metro, Tape → Tape+Metro)

분석 과정 상세 처리 방식 및 라이브러리 (scipy.stats)
공통 표본 추출 비교하는 두 조건(cond_a, cond_b) 모두에 데이터가 존재하는 피험자(공통 피험자 집합)만을 필터링하여 대응 표본 쌍(Pair)을 구성합니다.
차이 계산 및 결측치 표본 A와 B 중 하나라도 결측치(NaN)가 있으면 해당 피험자는 검정에서 제외합니다. 변화율(pct_change)은 (mean_diff / mean_a) * 100 으로 구합니다.
Wilcoxon 부호순위검정 본 데이터셋은 극소표본(N=6, 결측 시 N=5)에 해당하므로 정규성 검정(Shapiro-Wilk)의 검정력이 무의미합니다. 따라서 모수 검정(t-test)을 원천 배제하고 wilcoxon(a, b)를 호출하여 비모수적 통계 검정을 적용합니다.
효과 크기 (Effect Size: Cohen's d) 비모수 소표본에서는 유의수준(p < 0.05) 달성이 수학적으로 극도로 불리하므로(N=6 양측 최소 p=0.031), 실질적인 효과의 크기를 나타내기 위해 평균 차이를 차이값의 표준편차로 나눈 Cohen's d (effect_size_d)를 함께 산출하여 임상적 유의성을 평가합니다.
