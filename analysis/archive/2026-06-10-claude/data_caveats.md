# 데이터 단서 (Data Caveats) — 해석 전에 반드시 고려

작성: 2026-06-10 · 작성자: Claude

이 항목들은 결과 해석의 **신뢰 가능 범위**를 정한다. 모든 수치는 위 CSV에서 직접 인용.

## 1. ❓ 러닝 속도 통제 여부가 데이터 파일에 없음 — 충격 결과 해석의 최대 변수
- CSV에 **속도(velocity) 필드가 없다.** `duration_s`(약 110.8–124.4초)와 step 수만 있다.
- 핵심결과①(메트로놈→충격 proxy↑) 해석은 **속도 통제 여부에 결정적으로 의존**한다. 검증된 선행연구(Heiderscheit 2011 등)는 모두 **정속**에서 케이던스↑ → loading↓를 보였다.
- 만약 메트로놈으로 케이던스를 올릴 때 **속도가 함께 증가**했다면, 충격 proxy 증가는 생체역학적 발견이 아니라 **설계 교란(속도 효과)**이다.
- `analysis/results_report.html` IMU 한계 절은 "트레드밀, 금속 프레임"을 언급 → **트레드밀 사용 추정.** 트레드밀 벨트 속도가 조건 간 고정이었다면 속도는 통제된 것이고, 그렇다면 충격 proxy↑는 더 흥미로운(진짜) 결과가 된다.
- **조치:** 프로토콜에서 (a) 트레드밀/오버그라운드, (b) 조건 간 속도 고정 여부, (c) 메트로놈 목표 BPM과 self-selected cadence 대비 증가폭을 **반드시 명시**해야 한다. 확인 전에는 충격 결과를 "속도 통제 가정 하의 탐색 결과"로만 기술.

## 2. 케이던스는 수기 입력(정수)이라 다른 지표와 출처가 다름
- `cadence_steps_per_min` 값이 전부 정수(예: Control 168·192·204·176·186·180)다. 커밋 `d7da46c "use manual cadence"` 기준 **수기 카운트**다.
- 즉 케이던스만 사람이 센 값이고, 충격·CV·발목·골반은 IMU 파생값이다. **provenance가 다름**을 명시해야 하며, 케이던스는 정수 해상도라 작은 변화는 둔감하다.
- (영향 작음, 단 보고 시 분리 기술 권장.)

## 3. ⚠️ 골반 Roll SD의 C→T +51%는 6명 중 2명이 만든 값
- `pelvis_roll_sd_deg` (Control→Tape):
  - Control: 박민규 8.48, 안승진 10.79, 오승민 8.11, 이상희 7.91, 진현준 8.86, 한상윤 8.55 (≈8–11)
  - Tape: 박민규 9.64, 안승진 9.79, **오승민 21.20**, 이상희 8.47, **진현준 22.09**, 한상윤 8.41
- 평균 8.78→13.27 (+51.03%, p=0.219)는 **오승민·진현준 2명**의 급등(≈21–22°)이 견인. 나머지 4명은 거의 불변.
- Roll SD는 보고서 IMU 한계 절에서도 **자기장 간섭(AHRS yaw/roll) 취약 지표**로 지목됨. → Roll SD 변화는 2명 아티팩트 + 추정오차 가능성이 커서 **단정 금지.** Pitch SD가 더 신뢰 가능.

## 4. 표본 n이 지표·비교마다 5↔6으로 바뀜
- C→M: **n=5** (박민규 metro 데이터 결측/제외).
- C→T: n=6.
- C→T+M, T→T+M의 **발목 지표: n=5** (진현준 Tape+Metro 발목 이상치 제외).
- 비교·지표마다 검정 대상이 다르므로, 결과를 한데 묶어 "N=6"으로 일반화하지 말 것. 표마다 n을 병기.

## 5. step interval CV의 절대값이 매우 큼(12–34%) — 타이밍 변동성 proxy의 한계
- `step_interval_cv_pct` (Control): 박민규 12.05, 안승진 33.56, 오승민 34.09, 이상희 15.38, 진현준 33.22, 한상윤 28.18. **피험자 간 편차가 12%~34%로 매우 큼.**
- 이 지표는 shank 합성가속도 peak 간 간격의 CV다(파이프라인: prominence 0.2g, distance 280ms, IQR 필터). 따라서 **peak 검출 품질(누락/이중검출)과 좌우 비대칭 혼입**에 민감하다.
- 〈미재검증 일반 배경〉 보행 변동성 문헌에서 정상 성인 정속 보행의 stride-time CV는 통상 낮은 한 자릿수(%)로 알려져 있다(예: Hausdorff 2005 — *본 세션에서 Springer 접근 제한으로 전문 재검증 못 함, 수치 인용은 보류*). 본 데이터의 12–34%는 그보다 훨씬 크다.
- **함의:** CV의 **절대값**을 생물학적 stride-time variability로 직접 해석하기 어렵다. 다만 **같은 피험자 내 조건 간 상대 변화**(특히 유의했던 T→T+M +16.41%)는 의미가 상대적으로 보존된다. 그래도 결론은 "noisy timing proxy의 상대 변화"로 한정하고, 가능하면 peak 검출 품질(좌우 분리, 결측률)을 점검할 것.

## 6. 충격 지표는 IMU 합성가속도 proxy (GRF 아님)
- `shank_mean_peak_g`, `shank_resultant_rms_m_s2`는 정강이 IMU 합성가속도 기반 **proxy**다. GRF impulse/force가 아니다.
- 따라서 GRF 기반 선행연구(Heiderscheit 등)와 **방향 수준 비교**만 가능하고, 수치 등치는 금지. (핵심결과① 해석의 전제) → [evidence_excerpts_verified.md](evidence_excerpts_verified.md) A절 참조.
